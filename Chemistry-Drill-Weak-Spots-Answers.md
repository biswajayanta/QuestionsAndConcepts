## PART A: The "why" step (1 mark each)

For each, the mark goes to the **cause**. A sentence that only restates the question gets 0.

| Q | Model answer | Common wrong answer |
|---|---|---|
| A1 | Because carbon has 4 valence electrons, and losing 4 or gaining 4 takes too much energy (gaining 4 would put 10 electrons round a nucleus with 6 protons, which it cannot hold), so it **shares** electrons. | "Because it forms strong C–C bonds" (that is catenation, a different property). "Nuclear force" is the wrong term, use "energy". |
| A2 | Because the **forces between molecules** get stronger as the molecular mass increases. | "Because more bonds are present which are harder to break". Boiling does not break covalent bonds. |
| A3 | Because the **calcium and magnesium salts of detergents are soluble in water**, so no scum forms. | "Detergents don't react with the ions". They do, but the product is soluble. |
| A4 | Because they **react vigorously with the oxygen and moisture in air** (and can catch fire), and kerosene **keeps air and moisture away**. | "Because they corrode easily". |
| A5 | Because of the **strong electrostatic forces of attraction between oppositely charged ions**, which need a lot of energy to overcome. | "Because it is an ionic compound" (restates the question). |
| A6 | Because in the solid the **ions are held in fixed positions**, but in the molten state the ions are **free to move** and carry the current. | Saying "electrons move". It is ions that carry the current in molten NaCl. |
| A7 | Because sodium has a **greater affinity for oxygen than carbon does**, so carbon cannot take the oxygen away from it. | "Because sodium is more reactive than carbon" is accepted. "It cannot be displaced" alone is too thin. |
| A8 | Because ethene has a **double bond**, one of which can open up to add atoms, whereas ethane has only single bonds. | "Because ethene is more reactive". That is not a cause. |

## PART B: Conditions and types (½ for equation and condition, ½ for type)

| Q | Equation with condition | Type |
|---|---|---|
| B1 | 2CH3COOH + Na2CO3 → 2CH3COONa + H2O + CO2 (**no catalyst needed**). Product: sodium ethanoate. | Neutralisation (acid + carbonate) |
| B2 | CH3CH2OH → CH3COOH, with **alkaline KMnO4 (heat), or acidified K2Cr2O7**, on the arrow | Oxidation |
| B3 | CH3CH2OH → CH2=CH2 + H2O, with **conc. H2SO4, 443 K** on the arrow | Dehydration |
| B4 | CH3COOH + C2H5OH → CH3COOC2H5 + H2O, with **conc. H2SO4** on the arrow. Product: ethyl ethanoate (an ester). | Esterification |
| B5 | CH2=CH2 + H2 → CH3–CH3, with **Ni** on the arrow | Addition (hydrogenation) |
| B6 | CH4 + Cl2 → CH3Cl + HCl, with **sunlight** on the arrow | Substitution |
| B7 | 2ZnS + 3O2 → 2ZnO + 2SO2 (**heat, excess air**). The product is the **oxide**, not the metal. | Roasting |
| B8 | CH3COOC2H5 + NaOH → CH3COONa + C2H5OH (**no catalyst needed**). Products: sodium ethanoate and ethanol. | Saponification |

**Rule to remember:** conc. H2SO4 is needed only for **esterification (B4)** and for **dehydrating ethanol (B3)**. Neutralisation (B1) and saponification (B8) need no catalyst.

## PART C: Drawing structures (1 mark each)

For each, the mark is for the correct structure with the group marked.

**C1. Ethanoic acid (functional group –COOH):**
```
      H   O
      |   ‖
  H — C — C — O — H
      |
      H
```
Check: the H of the acid is on the **oxygen**, and the carbonyl carbon has 4 bonds (one to the CH3 carbon, a double bond to O, one to the other O).

**C2. Propanone (functional group >C=O, a ketone):**
```
      H   O   H
      |   ‖   |
  H — C — C — C — H
      |       |
      H       H
```
Check: the C=O is on the **middle** carbon, with a CH3 on each side. Each carbon has exactly 4 bonds.

**C3. Propanal (functional group –CHO, an aldehyde):**
```
      H   H   O
      |   |   ‖
  H — C — C — C — H
      |   |
      H   H
```
Check: the C=O is on the **end** carbon, and that carbon also carries one H.

**C4. The two isomers of butane (C4H10):**
```
  H   H   H   H           H   H   H
  |   |   |   |           |   |   |
H—C — C — C — C—H       H—C — C — C—H
  |   |   |   |           |   |   |
  H   H   H   H           H   |   H
                              H—C—H
                                  |
                                  H
```
Left: butane (a straight chain of 4 carbons). Right: 2-methylpropane (isobutane), a chain of 3 carbons with a CH3 branch on the middle carbon. Each has 10 hydrogens.
